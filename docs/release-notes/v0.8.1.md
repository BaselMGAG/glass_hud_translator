## What's new in v0.8.1

A small release about one thing: making automatic mode feel like the same app as pressing the key
yourself.

**Game dialogue is noticed twice as fast.** The app looks at the screen four times a second now
instead of twice, so a new line is seen within a quarter of a second rather than half of one. What it
does *not* do is wait less once it has seen the line — it still wants half a second of the text
holding still before it translates. That half second is the whole safety margin: without it, a line
that pauses in the middle of appearing gets translated half-written, which costs a request to show a
fragment and then a second request for the same sentence once it finishes.

So the change is sensitivity without duplication. From a line appearing to the Arabic being asked
for is about a third of a second quicker on average, and when the app has to read the text to be
sure, the two readings it compares are now a quarter of a second apart rather than half.

**Pressing the translate key while automatic mode was working used to do nothing at all.** No
answer, no message, nothing on screen — and it happened at exactly the moment you reach for that
key, which is when automatic mode looks like it has missed something. It now waits for the cycle in
progress and then answers, and tells you if the wait runs out. A poll can be dropped because another
one is a quarter of a second behind it; a key press is a question somebody asked out loud.

**And a key press no longer costs the next automatic line.** Pressing it put the Arabic on screen
without telling the part of the app that decides whether the screen has changed — so the next cycle
treated that same line as new, read it all over again, and threw the result away as a repeat. All
correct, and completely wasted, in the one place the delay was being complained about.

**"Did it actually skip a line?"** is now a question with an answer. The self-test counts lines that
were read and then refused, which is the only thing that is genuinely a dropped line rather than a
slow one. If that number is zero and a line still went missing, the cause is somewhere else — and
that is worth knowing before anybody goes looking.

Video mode is untouched: same waiting, same floor, same spending. Rapid subtitles cost what they
cost.
