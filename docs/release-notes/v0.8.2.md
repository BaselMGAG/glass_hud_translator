## What's new in v0.8.2

A fix release, from one very good observation: **nudging the dialogue window with the mouse is
caught instantly, but text changing on a window that is standing still can be missed.**

The pixels are the same problem in both cases, so the pixels were not the problem. What differs is
whether the app happened to be busy. Nudging the window happens while it is idle and watching;
the next line arrives while it is still waiting for the translation of the last one.

**The loop used to rest a quarter of a second after every cycle — including after a translation
that had already blocked it for a whole second.** So the moment it was furthest behind was the
moment it waited longest before looking again. It is paced on a schedule now: it sleeps whatever is
left of the interval, which after real work is nothing at all.

**The one decision that could silently swallow every remaining line now gets checked.** "Nothing has
changed" is the answer that skips reading the text, which makes it the only mistake here that cannot
correct itself on the next frame — every other wrong answer gets a fresh opinion a moment later. If
it is ever wrong, the app translates one line and then reports nothing changed for as long as you
leave it running. After fifteen seconds of that answer it now reads the words anyway and checks. It
costs one local pass and no quota: if the words really are unchanged, they are dropped before
anything is sent.

**And a measurement that was counted in polls instead of seconds** silently halved itself when the
poll rate went up in v0.8.1 — the same defect that release fixed in the file next door, missed in
the same change. It is measured in seconds at any poll rate now.

The self-test also records how long the app went without looking at the screen, so a line that was
genuinely dropped can be told apart from one that was merely late.

---

**One limit worth knowing rather than chasing.** A line costs the wait for the text to hold still,
plus the round trip to the translator — and the app is not watching the screen during the second of
those. It keeps up comfortably with a player advancing every second and a half. Faster than that and
lines will be missed, not because a setting is wrong but because the answer for the previous line
has not come back yet. Pressing the translate key still works at any speed, and no longer does
nothing while automatic mode is mid-cycle.
